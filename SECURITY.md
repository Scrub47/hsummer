# Security policy

Hsummer is a small private beta run by Isaac Hsu. If you find a vulnerability, report it in private.

## How to report

Open a private advisory:

https://github.com/Scrub47/hsummer/security/advisories/new

That form stays off the public issue list. If the link says reporting is not enabled, the project owner still has to turn on private vulnerability reporting under the repository's security settings.

Do not file a public GitHub issue for a security problem. Do not include live API keys, session cookies, or another person's circle content in the report.

## What helps

- What you did, and what you expected
- What happened instead
- The page or request involved
- The commit or date, if you know it

## After a report

Isaac reads these when he can. There is no bounty and no company behind the beta. Please wait until a fix is out, or 90 days, whichever comes first, before describing the issue in public.

This page is the project's reporting policy. It is not legal advice.
